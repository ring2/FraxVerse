## 1. 模块概述

### 1.1 职责边界

本模块负责：

- 用户账号管理（创建/密码修改）
- JWT Token 生成/验证/续期/撤销
- 登录鉴权与安全防护（限次/黑名单）
- 首次启动系统初始化
- 会话管理（单用户单会话）

**不负责**：

- 前端UI渲染逻辑（见 DD-08）
- 其他业务模块的权限控制（各模块自行调用鉴权中间件）
- LLM API Key 的运行时管理（仅初始化时存储）

### 1.2 依赖关系

```
DD-01 认证模块
  ├── 依赖 PostgreSQL — 用户表/会话表
  ├── 依赖 Redis — Token黑名单 + 登录限次计数 + 活跃会话
  ├── 依赖 python-jose — JWT编解码
  ├── 依赖 passlib[bcrypt] — 密码哈希
  └── 被依赖 — 所有其他模块的鉴权中间件
```

**伪代码**：

```
# 幂等性：否（仅可调用一次）
function init_system(request: InitRequest) -> InitResponse:
    # 1. 前置检查：系统是否已初始化
    user_count = [DB] SELECT COUNT(*) FROM users
    if user_count > 0 then
        [RAISE] Error(00005, "系统已初始化，不可重复调用")
    end if

    # 2. 参数校验
    validate_username(request.username)       # 3-20字符, 字母数字下划线
    validate_password(request.password)       # 6-50字符
    validate_api_key(request.config.deepseekApiKey)  # 非空, sk-开头
    # claudeApiKey可选, 不校验空值

    # 3. 事务：创建用户 + 写入配置
    tx = [DB] begin_transaction(isolation=SERIALIZABLE)
    try:
        # 3.1 创建用户
        password_hash = bcrypt_hash(request.password, cost=12)
        user = [DB] INSERT INTO users (username, password_hash, is_initialized)
                VALUES (request.username, password_hash, TRUE)
                RETURNING id, username

        # 3.2 写入系统配置
        [DB] INSERT INTO system_config (config_key, config_value, config_type) VALUES
            ('deepseek_api_key', encrypt(request.config.deepseekApiKey), 'string'),
            ('claude_api_key', encrypt(request.config.claudeApiKey), 'string'),
            ('trade_mode', request.config.tradeMode, 'string'),
            ('data_source_akshare', str(request.config.dataSourceAkshare).lower(), 'bool'),
            ('data_source_miniqmt', str(request.config.dataSourceMiniqmt).lower(), 'bool'),
            ('system_initialized', 'true', 'bool')

        tx.commit()
    except UniqueViolation:
        tx.rollback()
        [RAISE] Error(00005, "系统已初始化")
    except:
        tx.rollback()
        [RAISE] Error(00008, "初始化失败")
    end try

    # 4. 生成Token对（与登录相同逻辑）
    tokens = generate_token_pair(user.id, user.username, request.ip_address, request.user_agent)

    # 5. 异步触发后台初始化任务（不阻塞响应）
    async_trigger("first_data_sync")    # 首次数据同步
    async_trigger("experience_cold_start")  # 经验库冷启动
    [LOG] INFO "系统初始化完成" username = user.username

    return InitResponse(tokens=tokens, user=user)
end function
```

**伪代码**：

```
# 幂等性：否（每次登录生成新Token）
function login(request: LoginRequest, client_ip: string) -> LoginResponse:
    # 1. 检查IP是否被锁定
    lock_key = "login_lock:{client_ip}"
    is_locked = [REDIS] GET lock_key
    if is_locked is not None then
        ttl = [REDIS] TTL lock_key
        [RAISE] Error(40111, "登录尝试过多，请{ttl//60}分钟后再试")
    end if

    # 2. 查找用户
    user = [DB] SELECT * FROM users WHERE username = request.username
    if user is None then
        handle_login_failure(client_ip)
        [RAISE] Error(40110, "用户名或密码错误")  # 不透露是用户名还是密码错误
    end if

    # 3. 验证密码
    password_valid = bcrypt_verify(request.password, user.password_hash)
    if not password_valid then
        handle_login_failure(client_ip)
        [RAISE] Error(40110, "用户名或密码错误")
    end if

    # 4. 撤销旧会话（单用户单会话策略）
    revoke_all_user_sessions(user.id)

    # 5. 生成新Token对
    tokens = generate_token_pair(user.id, user.username, client_ip, request.user_agent)

    # 6. 更新用户登录信息
    [DB] UPDATE users SET
        last_login = NOW(),
        login_count = login_count + 1,
        updated_at = NOW()
    WHERE id = user.id

    # 7. 清除登录失败计数
    [REDIS] DEL "login_fail:{client_ip}"

    [LOG] INFO "用户登录成功" username = user.username ip = client_ip

    return LoginResponse(tokens=tokens, user=user)
end function


# 登录失败处理（计数+锁定）
function handle_login_failure(client_ip: string):
    fail_key = "login_fail:{client_ip}"
    fail_count = [REDIS] INCR fail_key
    [REDIS] EXPIRE fail_key 900  # 15分钟TTL

    if fail_count >= 5 then
        # 触发锁定
        [REDIS] SET "login_lock:{client_ip}" = "1" WITH TTL 900
        [LOG] WARNING "IP登录锁定" ip = client_ip fail_count = fail_count
    else
        [LOG] INFO "登录失败" ip = client_ip fail_count = fail_count
    end if
end function


# 撤销用户所有会话
function revoke_all_user_sessions(user_id: int):
    # 1. 查找所有活跃会话
    active_sessions = [DB] SELECT * FROM sessions
                       WHERE user_id = user_id AND revoked = FALSE

    # 2. 批量撤销
    for session in active_sessions do
        # 将Token加入Redis黑名单
        revoke_token_in_redis(session.access_jti, session.access_expires)
        revoke_token_in_redis(session.refresh_jti, session.refresh_expires)
    end for

    # 3. 数据库批量标记撤销
    [DB] UPDATE sessions SET revoked = TRUE WHERE user_id = user_id AND revoked = FALSE

    # 4. 清除Redis活跃会话记录
    [REDIS] DEL "active_session:{user_id}"
end function


# 将Token加入Redis黑名单
function revoke_token_in_redis(jti: string, expires_at: datetime):
    ttl_seconds = (expires_at - now()).total_seconds()
    if ttl_seconds > 0 then
        [REDIS] SET "token_blacklist:{jti}" = "1" WITH TTL int(ttl_seconds)
    end if
    # Token过期后自动从Redis清除
end function
```

**请求**：

```json

```

| 字段 | 类型 | 必选 | 校验规则 |
|:-----|:-----|:----:|:---------|
| refreshToken | string | ✅ | 非空，合法JWT |

**响应（成功）**：

```json
{
  "code": 0,
  "message": "续期成功",
  "data": {
    "accessToken": "eyJhbGciOi...(新)",
    "refreshToken": "eyJhbGciOi...(新)",
    "tokenType": "Bearer",
    "accessExpiresIn": 86400,
    "refreshExpiresIn": 604800
  },
  "timestamp": "2026-05-01T09:30:00+08:00"
}
```

**错误响应**：

| 错误码 | HTTP | 场景 |
|:-------|:-----|:-----|
| 40102 | 401 | Refresh Token已过期 |
| 40103 | 401 | Refresh Token已撤销 |
| 40105 | 401 | Refresh Token无效 |

**伪代码**：

```
# 幂等性：否（每次续期生成新Token对，旧Token对撤销）
function refresh_token(request: RefreshRequest) -> RefreshResponse:
    # 1. 解码Refresh Token
    payload = jwt_decode(request.refreshToken, secret = [CONFIG] "jwt.secret")
    if payload is invalid then
        [RAISE] Error(40105, "Refresh Token无效")
    end if

    # 2. 校验Token类型
    if payload.type != "refresh" then
        [RAISE] Error(40105, "非Refresh Token")
    end if

    # 3. 检查过期
    if payload.exp < now_timestamp() then
        [RAISE] Error(40102, "Refresh Token已过期")
    end if

    # 4. 检查黑名单
    is_revoked = [REDIS] GET "token_blacklist:{payload.jti}"
    if is_revoked is not None then
        [RAISE] Error(40103, "Refresh Token已撤销")
    end if

    # 5. 查找会话记录
    session = [DB] SELECT * FROM sessions
              WHERE refresh_jti = payload.jti AND revoked = FALSE
    if session is None then
        [RAISE] Error(40103, "会话已撤销")
    end if

    # 6. 撤销旧Token对
    revoke_token_in_redis(session.access_jti, session.access_expires)
    revoke_token_in_redis(session.refresh_jti, session.refresh_expires)
    [DB] UPDATE sessions SET revoked = TRUE WHERE id = session.id

    # 7. 生成新Token对
    user = [DB] SELECT * FROM users WHERE id = payload.sub
    tokens = generate_token_pair(user.id, user.username, session.ip_address, session.user_agent)

    [LOG] INFO "Token续期成功" username = user.username

    return RefreshResponse(tokens=tokens)
end function
```

        [RAISE] Error(40121, "确认密码与新密码不一致")

    if not password_valid then

        [REDIS] EXPIRE fail_key 900

        updated_at = NOW()
    WHERE id = user.id

    # 5. 撤销所有会话（强制重新登录）
    revoke_all_user_sessions(user.id)

    # 6. 清除限次计数
    [REDIS] DEL "pwd_change_fail:{current_user.sub}"

    [LOG] INFO "密码修改成功，所有会话已撤销" username = user.username

    return Response(message="密码修改成功，请重新登录")

function generate_token_pair(user_id: int, username: string,
                             ip_address: string, user_agent: string) -> TokenPair:

    access_jti = uuid_v4()
    refresh_jti = uuid_v4()

    # 2. 计算过期时间
    now = current_timestamp()
    access_expires = now + [CONFIG] "jwt.access_expire_hours" * 3600   # 默认24h
    refresh_expires = now + [CONFIG] "jwt.refresh_expire_days" * 86400 # 默认7d

    # 3. 构造JWT Payload
    access_payload = {
        "sub": username,
        "user_id": user_id,
        "exp": access_expires,
        "iat": now,
        "type": "access",
        "jti": access_jti
    }

    refresh_payload = {
        "sub": username,
        "user_id": user_id,
        "exp": refresh_expires,
        "iat": now,
        "type": "refresh",
        "jti": refresh_jti
    }

    secret = [CONFIG] "jwt.secret"
    algorithm = "HS256"
    access_token = jwt_encode(access_payload, secret, algorithm)
    refresh_token = jwt_encode(refresh_payload, secret, algorithm)

    [DB] INSERT INTO sessions
        (user_id, access_jti, refresh_jti, ip_address, user_agent,
         access_expires, refresh_expires)

         access_expires, refresh_expires)

        refresh_token = refresh_token,
        token_type = "Bearer",

### 4.2 Token 验证（鉴权中间件核心）

# 幂等性：是
function validate_token(token: string) -> TokenPayload:
    [ASSERT] token is not empty

    # 1. JWT解码
    secret = [CONFIG] "jwt.secret"
    payload = jwt_decode(token, secret, algorithms=["HS256"])

    if payload is invalid then
        [RAISE] Error(40105, "Token无效")
    end if

    # 2. 类型校验（仅Accept Access Token）
    if payload.type != "access" then
        [RAISE] Error(40105, "非Access Token")
    end if

    # 3. 过期校验
    if payload.exp < now_timestamp() then
        [RAISE] Error(40102, "Token已过期")
    end if

    # 4. 黑名单校验（Redis查找，O(1)）
    is_revoked = [REDIS] GET "token_blacklist:{payload.jti}"
    if is_revoked is not None then
        [RAISE] Error(40103, "Token已撤销")
    end if

    # 5. 活跃会话校验（防止被踢用户用未过期Token访问）
    active_session = [REDIS] HGETALL "active_session:{payload.user_id}"
    if active_session is not None and active_session.access_jti != payload.jti then
        # 当前Token不是最新活跃Token，说明已被新登录踢掉
        [RAISE] Error(40103, "会话已被新登录替代")
    end if

    return TokenPayload(
        sub = payload.sub,
        user_id = payload.user_id,
        jti = payload.jti,
        exp = payload.exp,
        type = payload.type
    )
end function
```

## 5. 状态机与转换规则

### 5.1 系统初始化状态机

```
                    ┌─────────────┐
                    │   UNINIT    │  users表为空
                    │  (未初始化)  │  system_initialized = false
                    └──────┬──────┘
                           │
                    POST /auth/init 成功
                           │
                           ▼
                    ┌─────────────┐
                    │   INITED    │  users表非空
                    │  (已初始化)  │  system_initialized = true
                    └─────────────┘
                           │
                    ❌ 不可逆转
                    ❌ /auth/init 不可再次调用
                    ❌ /setup 页面不可再次访问
```

**转换规则**：
- UNINIT → INITED：仅通过 `POST /auth/init` 触发，原子操作
- INITED 是终态，不可回退

### 5.2 用户会话状态机

```
    ┌───────────┐  login成功  ┌───────────┐  logout  ┌───────────┐
    │  ABSENT   │ ──────────→ │   ACTIVE   │ ────────→│ REVOKED   │
    │  (无会话)  │             │  (活跃会话) │          │  (已撤销)  │
    └───────────┘             └─────┬─────┘          └───────────┘
         ↑ ↑                        │                      ↑
         │ │     refresh成功        │  密码修改             │
         │ │  ┌─────────────┐       │                      │
         │ │  │  RENEWING   │       │                      │
         │ └──│  (续期中)    │←──────┘                      │
         │    └─────────────┘   Token即将过期               │
         │                         │                        │
         │    新login              │ 踢旧会话               │
         │  ┌──────────────────────┘                        │
         │  │ 旧会话直接→REVOKED                            │
         │  │                                               │
         └──┴───────────────────────────────────────────────┘
              新login/密码修改 → 旧会话REVOKED → ABSENT
```

**转换规则**：

| 转换 | 触发条件 | 旧Token处理 | 新Token |
|:-----|:---------|:-----------|:--------|
| ABSENT → ACTIVE | login成功 | 无 | 生成新Token对 |
| ACTIVE → RENEWING | Token即将过期 | 保持 | 生成新Token对，旧Token加入黑名单 |
| ACTIVE → REVOKED | logout/密码修改 | 加入黑名单 | 无 |
| ACTIVE → REVOKED | 新login | 旧Token加入黑名单 | 生成新Token对 |
| RENEWING → ACTIVE | refresh成功 | 旧Token加入黑名单 | 生成新Token对 |
| REVOKED → ABSENT | 前端清除Token | 无 | 无 |

**关键约束**：
- 单用户仅允许1个ACTIVE会话
- 新登录自动踢掉旧会话（Token加入黑名单，Redis清除）
- 密码修改后所有会话立即撤销

### 5.3 登录限次状态机

```
    ┌──────────┐  失败1-4次  ┌──────────┐  第5次失败  ┌──────────┐
    │  NORMAL   │ ──────────→ │ WARNING   │ ─────────→ │  LOCKED   │
    │  (正常)    │             │ (计数中)   │            │  (锁定15m) │
    └──────────┘              └──────────┘             └─────┬──────┘
         ↑                                                  │
         │              15分钟无失败/TTL过期                  │
         └──────────────────────────────────────────────────┘
```

**Redis实现**：
- `login_fail:{ip}`：计数器，15分钟TTL，INCR递增
- `login_lock:{ip}`：锁定标记，第5次失败时设置，15分钟TTL
- 锁定期内直接返回429，不验证密码（防暴力破解）

| 40121 | 400 | 确认密码不一致 | confirmPassword != newPassword |

### 6.2 异常场景处理

| 场景 | 处理策略 |
|:-----|:---------|
| JWT_SECRET未配置 | 服务启动时检查，缺失则拒绝启动 |
| Redis不可用 | 鉴权降级：跳过黑名单检查，日志告警；登录限次降级：允许登录但不计数 |

| bcrypt验证超时 | cost factor从12降为10，记录告警日志 |
