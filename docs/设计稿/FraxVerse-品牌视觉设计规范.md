# 碎片宇宙（FraxVerse）品牌视觉设计规范

> 版本：V1.0
> 日期：2026-05-01
> 核心哲学：**交易修心、心念为碎片、宇宙为心之投影**
> Slogan：万千心念皆碎片，一怀内观即宇宙

---

## 1. 品牌释义

### 1.1 名称由来

| 名称 | 含义 |
|:-----|:-----|
| **碎片宇宙** | 心念为碎片，内观即宇宙。每一次交易决策都是一枚心念碎片，碎片聚合映射出交易者的内心世界 |
| **FraxVerse** | Frax = Fragment（碎片）+ Verse = Universe（宇宙）。取"碎片的宇宙"之意 |

### 1.2 哲学内核

```
交易修心 ─────── 交易不是对抗市场，而是与内心的对话
  │
心念为碎片 ───── 每个信号、决策、经验都是一枚碎片
  │
宇宙为心之投影 ── 市场是内心的镜子，持仓星图是心念的投影
```

三个层次的关系：
1. **碎片层**：信号、数据、新闻 → 心念碎片
2. **聚合层**：Agent讨论、策略评估 → 碎片聚合为星图
3. **内观层**：经验库、复盘 → 心之投影，观照自身

## 2. 视觉系统

### 2.1 色彩体系

| 角色 | 色值 | RGB | 用途 | 哲学映射 |
|:-----|:-----|:----|:-----|:---------|
| 宇宙深空 | `#06060f` | 6,6,15 | 全局背景 | 心之深渊 |
| 深空表面 | `#0a0a1a` | 10,10,26 | 卡片/面板背景 | 内观之境 |
| 星云紫深 | `#534AB7` | 83,74,183 | 边框/强调/标签 | 心念之根 |
| 星云紫 | `#7F77DD` | 127,119,221 | 主色调/粒子/连线 | 心念之色 |
| 星云紫浅 | `#AFA9EC` | 175,169,236 | 辅助强调/悬浮态 | 心念之光 |
| 星云紫辉 | `#CECBF6` | 206,203,246 | 文字高亮/品牌名 | 观照之光 |
| 上涨红 | `#F0997B` | 240,153,123 | 涨/买入信号 | 红为涨（A股惯例） |
| 下跌绿 | `#5DCAA5` | 93,202,165 | 跌/卖出信号 | 绿为跌（A股惯例） |
| 观照琥珀 | `#EF9F27` | 239,159,39 | 持有/观望 | 观而不动 |
| 碎片连接 | `rgba(127,119,221,0.08)` | — | 粒子连线 | 心念互联 |

### 2.2 粒子特效规范

```
画布：全屏Canvas，z-index: 0，pointer-events: none
粒子数量：100-150个
粒子颜色：#7F77DD（星云紫）
粒子大小：0.3 - 1.5px
粒子透明度：0.1 - 0.5（脉冲呼吸）
粒子速度：0.3px/frame（缓慢漂浮）
连线距离：< 120px
连线透明度：(1 - dist/120) × 0.08
背景色：#06060f（宇宙深空）
```

### 2.3 品牌标识（Logo）

**核心元素：**
- 三层椭圆轨道（不同旋转速度：12s/8s/5s，方向交替）
- 中心光点（脉冲呼吸效果 pulse-glow）
- 碎片散点（3-5个，分布在轨道上）

**动画效果：**
- 轨道持续旋转 → 心念围绕核心运行
- 中心光点脉冲 → 观照的呼吸
- 碎片随轨道运动 → 心念的流转

## 4. 组件视觉规范

### 4.1 碎片卡片（Fragment Card）

```
背景：rgba(15, 15, 35, 0.85)
边框：1px solid rgba(83, 74, 183, 0.2)
圆角：12px
悬浮态：border-color → rgba(127, 119, 221, 0.4)
微光扫过：shimmer动效，4s周期
信号类型标记：
  - 买入：红色光晕 #F0997B
  - 卖出：绿色光晕 #5DCAA5
  - 持有：琥珀光晕 #EF9F27
```

### 4.2 星图组件（Star Map）

```
中心：观照核心（pulse-glow脉冲）
轨道：3层椭圆，虚线，rgba(83, 74, 183, 0.15)
星体：持仓个股
  - 大小：持仓金额映射
  - 颜色：盈亏映射（红涨绿跌）
  - 光晕：box-shadow 0 0 8px
连线：星体间相关性的虚线连接
```

### 4.3 导航栏

```
背景：rgba(6, 6, 15, 0.7) + backdrop-filter: blur(20px)
边框底部：1px solid rgba(83, 74, 183, 0.2)
品牌名：serif字体，#CECBF6，letter-spacing: 2px
FraxVerse副标题：sans-serif，11px，#8887a8，letter-spacing: 3px
```

### 4.4 侧边栏

```
背景：rgba(6, 6, 15, 0.5) + backdrop-filter: blur(10px)
底部：心经竖排文字（writing-mode: vertical-rl）
  "交易修心 心念为碎片 宇宙为心之投影"
  字体：serif，12px，#5a5880
```

## 5. 交互动效

| 动效 | 用途 | 参数 |
|:-----|:-----|:-----|
| 脉冲呼吸 | Logo中心/信号碎片 | 2s ease-in-out infinite |
| 微光扫过 | 指标卡片 | 4s ease-in-out infinite |
| 星轨旋转 | 内观宇宙/Logo轨道 | 8-12s linear infinite |
| 碎片浮入 | 新信号出现 | translateY(10px)→0, opacity 0→1, 0.3s |
| 连线渐显 | 粒子连线 | opacity 0→0.08, 0.5s |
