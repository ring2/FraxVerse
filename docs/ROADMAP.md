## ⬜ 长期 — 可做可不做

| 项目 | 说明 | 价值 |
|:----|:-----|:----:|
| UI 自动化测试（Playwright） | 前端页面不再大改时写 | 防止回归 |
| 性能/压力测试 | 数据量到 500+ 股票时 | 瓶颈预判 |
| 安全渗透测试 | 上真实资金前必须做 | 防攻击 |
| 多账户支持 | 支持跟单/多策略分账户 | 扩展性 |
| 策略市集 | 用户可上传策略回测 | 社区化 |
